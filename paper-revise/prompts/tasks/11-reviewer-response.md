# Task 11 — Draft the response and audit review coverage

Follow `paper-revise/prompts/tasks/README.md`. Read both original review PDFs directly. Build the comment inventory early; finalize using task 10 and all technical handoffs.

Create a coverage matrix for every major and minor comment, including items omitted from the planning summary. For each, identify the responsible task, evidence, manuscript location, and status. Draft a concise, respectful point-by-point response stating the concern, actual change, and supporting result. Explain disagreements or unresolved limitations with evidence.

Deliver to `paper-revise/results/11-reviewer-response/` the response letter, coverage matrix, and actionable gap list for task 12. Use stable section/equation/figure identifiers; mark page or line references pending until a revised manuscript is built.

Acceptance: every reviewer request has a supported response or an explicit unresolved status. Do not claim experiments, revisions, or verification were completed merely because a prior prompt requested them.
