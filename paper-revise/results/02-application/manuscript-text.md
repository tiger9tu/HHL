# Proposed application text

To connect the resource framework to a concrete scientific computation, we use steady diffusion on a square domain. The conductivity is a(X,Y)=1+βX, homogeneous Dirichlet conditions prescribe zero temperature on the boundary, and a smooth polynomial source is chosen by the method of manufactured solutions. The requested classical output is the domain-averaged temperature, with absolute error at most 10⁻⁴ in fixed nondimensional units and delivery probability at least 0.99. Both quantum and classical pipelines approximate this same continuum scalar. This choice reflects the linear-functional output studied in quantum PDE algorithms, while making the discretization and quadrature errors independently checkable [1].

A conservative midpoint-flux discretization on an m-by-m interior grid has N=m² unknowns and maximum row and column sparsity five. Comparing its edge energy with the constant-conductivity Dirichlet Poisson operator gives max(1,κ₀/(1+β))≤κ₂(A)≤(1+β)κ₀, where κ₀=cot²[π/(2(m+1))]. Thus at fixed conductivity contrast the unpreconditioned condition number grows as Θ(N), while sparsity remains constant. This replaces the illustrative assumption κ=s=log N with a derived application-specific relation.

The manufactured temperature is U=X(1−X)Y(1−Y)(1+XY). Its exact domain average is 5/144. The complete mesh error is bounded by 5(2h²−h⁴)/144+4βh⁴N/(27λ₀), where h=1/(m+1) and λ₀=8h⁻²sin²(πh/2). We allocate one quarter of the total tolerance to this error and account separately for algebraic solution, representation, output estimation and arithmetic errors. For the default m=127 and β=9, this bound is approximately 8.30×10⁻⁶. Preparing a normalized quantum solution is insufficient: the discrete scalar h²Σx_i also requires the solution norm and a coherently defined signed overlap with the uniform state. Input preparation, oracle evaluation, norm recovery and repetitions must enter the full resource calculation.

Both branches begin with the compact analytic problem specification. Arithmetic evaluation of the stencil and source provides a constructive quantum-access route, but a compiled reversible implementation and output-extraction cost remain to be supplied. No free QRAM or input state is assumed. Classical comparisons should include Poisson-preconditioned CG, whose symmetric preconditioned condition number is bounded by 1+β, as well as a sine-transform reduction to independent tridiagonal systems. Preconditioning has setup, application and storage costs. A quantum analogue must account additionally for transformed access, block normalization, input preparation and recovery; the classical conditioning bound cannot simply be inserted into an unchanged sparse QLSA model [2,3].

This case is a verification benchmark for specified solver pipelines. Its exact scalar answer and separable structure are available to all methods, so it does not establish an unrestricted application-level quantum advantage. Production claims require a nonmanufactured workload, calibrated classical implementations and complete quantum input/output costs. The parameter sweep and error certificates expose these requirements rather than providing a new crossover estimate.

[2] PETSc KSPCG documentation, https://petsc.org/release/manualpages/KSP/KSPCG/. Supports SPD eligibility and symmetric interpretation of preconditioning.
